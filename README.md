# نظام إدارة المستفيدين من المساكن الريفية
## Système de gestion des bénéficiaires des logements ruraux

نظام متكامل لإدارة بيانات المستفيدين من المساكن الريفية بواجهة رسومية احترافية.

---

## 🎯 المميزات الرئيسية

✅ **إدارة بيانات المستفيدين:**
- إضافة مستفيد جديد
- تعديل بيانات المستفيد
- حذف مستفيد
- عرض قائمة المستفيدين

✅ **إدارة الصور:**
- تحميل الصورة الشخصية
- عرض الصورة

✅ **البحث والفلترة:**
- البحث بالاسم
- البحث برقم CNI
- البحث بالعنوان

✅ **التقارير والإحصائيات:**
- عرض إحصائيات
- تصدير إلى Excel

✅ **قاعدة البيانات:**
- SQLite محلي آمن وموثوق

---

## 📋 متطلبات التشغيل

```
Python 3.8+
tkinter (مدمج مع Python)
sqlite3 (مدمج مع Python)
Pillow (للصور)
openpyxl (لتصدير Excel)
```

## 🔧 التثبيت

```bash
# استنسخ المستودع
git clone https://github.com/habibfcb79barca/Gestion_Beneficiaires_Logements_Ruraux.git

# انتقل إلى المجلد
cd Gestion_Beneficiaires_Logements_Ruraux

# ثبت المكتبات المطلوبة
pip install -r requirements.txt

# قم بتشغيل التطبيق
python main.py
```

## 🚀 الاستخدام

1. **تشغيل البرنامج:**
   ```bash
   python main.py
   ```

2. **إضافة مستفيد جديد:**
   - انقر على زر "إضافة"
   - ملأ البيانات
   - انقر "حفظ"

3. **البحث:**
   - استخدم حقل البحث لإيجاد المستفيدين

4. **التصدير:**
   - انقر "تصدير Excel" لتنزيل البيانات
